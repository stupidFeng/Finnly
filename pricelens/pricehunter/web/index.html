整体架构

适配器分层解耦，采集与呈现互不依赖

STEP 01

采集

平台适配器批量抓取，真实失败自动降级仿真源

STEP 02

清洗

全角归一、价格 / 销量 / 评分解析、品牌型号抽取

STEP 03

去重归组

SKU → 同款同价 → 标题相似度，跨平台同款聚类

STEP 04

分析

价格升序、MAD 异常检测、加权性价比评分与推荐

STEP 05

呈现

JSON / CSV / HTML 落盘 + 交互网页与趋势图

采集层 · adapters/

  • jd.py 搜索页 HTML + p.3.cn 价格接口批量取价
  • taobao.py g_page_config JSON 解析，依赖登录 Cookie
  • pdd.py 预留第三方合规数据服务接入点
  • simulated.py 固定种子的仿真数据源，保证离线可演示

处理层 · pipeline/

  • normalize.py 全角归一、价格/销量/评分解析、品牌型号抽取
  • dedupe SKU → 同款同价 → 标题相似度三重去重
  • analyze.py 同款归组、MAD 异常检测、加权性价比评分
  • trend.py 90 天趋势指标与「是否好价」信号

呈现层 · output

  • render.py 内联 SVG 的离线 HTML 报告
  • pipeline.py 落盘 JSON / CSV / HTML 三件套
  • server.py 本地 HTTP 服务，POST /api/search 实时运行
  • cli.py search / serve / build-demo 三个子命令
# 1. 采集并分析（真实抓取优先，失败自动降级模拟源）
python -m pricehunter search "机械键盘" --platforms jd,tb,pdd --limit 12 -v

# 2. 启动交互演示页面（浏览器打开 http://127.0.0.1:8765）
python -m pricehunter serve --open

# 3. 重建示例数据与演示页面
python -m pricehunter build-demo --keyword "机械键盘"

产物：out/<关键词>_<时间戳>.json / .csv / .html。仅用于个人学习与价格监测，请遵守目标平台的 robots 协议与服务条款。
